### 2. `e08c094`：修复“输出路径可覆盖原始文件”

**问题**：代码只做到“读的时候只读”，但 `--output data/sales_raw.xlsx` 会把原始数据直接写没，违反题目“不得修改原始文件”的硬约束。

**改动**（`src/report_gen.py`）：

```python
# 输出与原始文件指向同一文件时直接拒绝，避免把原始数据覆盖掉
input_file, output_file = Path(input_path), Path(output_path)
if input_file.resolve() == output_file.resolve():
    raise ReportError(
        f"输出路径与原始文件相同（{input_file}），会覆盖原始数据；请为 --output 指定其他文件。"
    )
```

**验证**：
- 新增用例 `tests/test_report_gen.py::test_拒绝把报表写到原始文件上`（含“多一层 `.`”的等价路径写法）
- 手工执行 `py -3.13 -m src.report_gen --input data/sales_raw.xlsx --output data/sales_raw.xlsx`
  → 打印可读错误，`exit=1`，原始文件字节未变
